---
name: Ground a spec in data
description: >-
  Use this when a PRD or brainstorm needs evidence from product analytics or
  support volume, not opinions.
---
Do not invent metrics. Pull them, then write them into the ChatPRD doc as evidence.

## Source order

1. What you already have from an earlier pull in this conversation.
2. Metabase (default product analytics).
3. Amplitude, if it is connected.
4. Google Analytics for web/marketing questions Metabase does not cover.
5. Intercom for support-volume or theme evidence. Do not dump ticket text into a spec.

## Steps

1. State the claim the spec is making (activation, retention, conversion, a funnel stall).
2. Query the connected analytics tool for that claim. Prefer the number and the window over a screenshot.
3. If another assistant already posted a weekday scorecard, reuse it instead of re-pulling the same charts.
4. Write the evidence into the ChatPRD doc (success metrics, rationale, or an Outcomes section). Mark the date and source.
5. If the connector is missing or the query is empty, say you do not have the number. Do not fabricate one.

## Rules

- One or two numbers that change the decision beat a dashboard dump.
- Never present placeholder figures as real.
